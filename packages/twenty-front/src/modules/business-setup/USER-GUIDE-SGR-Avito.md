# Руководство пользователя: SGR Avito Agent

## Что такое SGR Avito Agent?

SGR Avito Agent - это специализированный AI помощник, который автоматически активируется в плавающей кнопке чата для помощи в настройке интеграции с площадкой Avito.

## Когда активируется SGR Agent?

🎯 **Автоматическая активация:**
- Вы находитесь на этапе "Welcome" бизнес-настройки
- Кликаете на плавающую AI кнопку в правом нижнем углу
- Система автоматически создает специализированного SGR Avito агента

## Как использовать

### Шаг 1: Начало работы

1. **Убедитесь, что вы на этапе Welcome** бизнес-настройки
2. **Найдите плавающую кнопку AI** в правом нижнем углу экрана (иконка ✨)
3. **Кликните на кнопку** - автоматически откроется SGR Avito агент

### Шаг 2: Подготовка данных Avito

Перед началом работы подготовьте:

📋 **API данные Avito:**
- `CLIENT_ID` - идентификатор клиента API
- `CLIENT_SECRET` - секретный ключ API
- URL callback для OAuth (если требуется)

📦 **Информация о товарах:**
- Категории товаров для автоматизации
- Прайс-листы или файлы с товарами
- Настройки ценообразования

### Шаг 3: Взаимодействие с агентом

**Агент поможет вам:**

1. **Настроить API интеграцию**
   ```
   Пользователь: "Мой CLIENT_ID: abc123, CLIENT_SECRET: xyz789"
   Агент: ✅ Проверяю подключение к Avito API...
   ```

2. **Загрузить товары**
   ```
   Пользователь: "Загрузи товары из прайс-листа"
   Агент: 🚀 Анализирую файл и создаю объявления...
   ```

3. **Настроить автоматизацию**
   ```
   Агент: ⚙️ Настраиваю автоматическое обновление цен...
   ```

### Шаг 4: Мониторинг прогресса

Во время работы агента вы увидите:

- **🚀 Starting** - агент начинает задачу
- **⚙️ In Progress** - выполнение в процессе  
- **✅ Completed** - задача завершена
- **❌ Failed** - ошибка (с описанием проблемы)

## Troubleshooting

### Агент не активируется

**Проверьте:**
- ✅ Вы находитесь на этапе "Welcome" бизнес-настройки
- ✅ AI функциональность включена в workspace
- ✅ У вас есть права доступа к AI агентам

**Решение:**
- Обновите страницу и попробуйте снова
- Проверьте настройки workspace

### Ошибки API Avito

**Частые проблемы:**
- ❌ Неверный CLIENT_ID или CLIENT_SECRET
- ❌ Превышен лимит запросов к API
- ❌ Неправильные права доступа

**Решения:**
```
1. Проверьте корректность API ключей в личном кабинете Avito
2. Убедитесь, что у API есть необходимые права
3. Подождите, если превышен лимит запросов
```

### Загрузка товаров не работает

**Возможные причины:**
- 📁 Неподдерживаемый формат файла
- 📋 Неправильная структура данных
- 🏷️ Отсутствуют обязательные поля

**Решения:**
- Используйте CSV или Excel файлы
- Убедитесь, что есть колонки: название, цена, описание, категория
- Проверьте, что все обязательные поля заполнены

## Часто задаваемые вопросы

### ❓ Могу ли я использовать несколько API ключей?

Да, вы можете настроить несколько аккаунтов Avito в рамках одного workspace.

### ❓ Как часто обновляются цены?

Автоматическое обновление можно настроить от 1 раза в час до 1 раза в сутки.

### ❓ Можно ли загрузить товары из 1С?

Да, экспортируйте данные из 1С в CSV формат и загрузите через агента.

### ❓ Что делать, если превышен лимит API?

Подождите до сброса лимита (обычно в начале следующего часа) или используйте режим пакетной обработки.

### ❓ Как отменить автоматизацию?

В настройках интеграции отключите автоматическое обновление или удалите API ключи.
